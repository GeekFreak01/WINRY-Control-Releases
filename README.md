# WINRY Control

Программа для макропада **WINRY315** (и других VIA-макропадов) на Windows: кнопкам и крутилкам назначаются действия на компьютере, как в Stream Deck — сочетания клавиш, программы, ссылки, текст, звуки, громкость Windows, SteelSeries Sonar, OBS Studio, Voicemeeter, страницы, таймеры, колесо действий. Готовые наборы для Photoshop, DaVinci Resolve, браузера, Discord, Spotify, Premiere Pro и других программ.

Software for the **WINRY315** macropad (and other VIA macropads) on Windows: Stream Deck–style actions for buttons and knobs — shortcuts, apps, links, text, sounds, Windows volume, SteelSeries Sonar, OBS Studio, Voicemeeter, pages, timers, an action wheel.

## Скачать / Download

Последняя версия — в разделе [Releases](../../releases/latest):

- `WINRY-Control.exe` — обычная версия / regular build;
- `WINRY-Control-developer.exe` — версия для разработчиков (коды VIA, слои, диагностика) / developer build.

Установка не нужна: скачай и запусти. Нужна Windows 10 или 11. Программа сама проверяет обновления при запуске и показывает «Вышло обновление».

No installation: download and run. Windows 10 or 11. The program checks this page for updates at startup.

## Сообщить о проблеме / Report a problem

В программе: Настройки → Общие → «Сообщить о проблеме…» — откроется страница [Issues](../../issues) с заполненным описанием, а архив с журналами сохранится на рабочий стол (его можно приложить).

In the program: Settings → General → “Report a problem…”.
